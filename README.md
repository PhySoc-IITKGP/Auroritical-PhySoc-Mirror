# PhySoc Official Website

Welcome to the official repository for the Physics Society, IIT Kharagpur website. 
This project is built to showcase our team, events, and initiatives, featuring a modern, highly interactive web design.

## 🚀 Features

- **Responsive & Modern UI**: Built with vanilla HTML/CSS/JS, utilizing a custom design system with Glassmorphism and Neumorphic elements.
- **Dark/Light Themes**: Seamless theme toggling for enhanced accessibility and user preference.
- **Animated Interactions**: Staggered reveals, interactive physics animations on the canvas, and smooth page transitions.
- **Modular Components**: Uses `components.js` to inject standard headers and footers across multiple pages without server-side rendering.
- **Custom Fonts**: Typography powered by 'Outfit' and 'Inter'.

## 📁 Structure

- `/`: Home page featuring animations and quick links.
- `/officers`: Directory of the executive team, chairs, and senior fellows.
- `/announcements`: Timeline of latest news and upcoming events.
- `/about`: Details about the society's mission and history.
- `/contact`: Forms to reach out to the team.

## 🛠️ Development

Run this project locally by serving the files via a local web server (e.g., Live Server in VSCode or python `http.server`):

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## 🎨 Aesthetics

Our design philosophy focuses on premium aesthetics, incorporating deep colors, glowing accents, and smooth shadows (neumorphism) to create an engaging experience for physics enthusiasts.
